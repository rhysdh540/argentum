# Cera
Cera is a companion mod for Argentum that reimplements MCPatcher/OptiFine resource pack extensions, while having minimal performance overhead.

## Features
- Connected textures
- Dynamic lights
- Custom item textures
- Natural textures
- Better grass
- Custom skyboxes
- Custom GUIs
- Entity/GUI animated textures
- Random mob textures
- Custom world recoloring
- Emissive textures
- OptiFine Cosmetics (capes/seasonal hats)
- Custom block layers
- Custom loading screens
- Custom panorama
- HD fonts
- Full configurability through Argentum's video settings menu

The only thing missing but planned is custom entity models, which is being deferred at the moment due to its complexity.

Shaders will be their own mod.
